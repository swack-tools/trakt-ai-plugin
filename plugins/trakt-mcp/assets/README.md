It does not reproduce Trakt, Anthropic, OpenAI, studio, or film artwork and does not assert affiliation. No external stock art, fonts, screenshots, or logos are incorporated.

The icon is decorative beside the textual plugin name; the README supplies alternative text when displaying it.
