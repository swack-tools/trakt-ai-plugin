# Security reporting

Publisher: SwackTech LLC. For security-sensitive reports, email **security@swacktech.com**. Include a minimal reproduction, affected version, impact, and a safe reply contact. Do not publish exploit details, credentials, device codes, or personal viewing data in public issues. Avoid sending live secrets or unnecessary personal data by email.

For ordinary bugs, use https://github.com/swack-tools/trakt-ai-plugin/issues with sanitized reproduction steps. The private email contact was supplied by the owner on September 27, 2026; no inbox delivery test or response-time SLA is claimed. GitHub private vulnerability reporting was turned off at that audit.

Only the current main branch is maintained; no formal version-support window has been established. Submission-branch changes remain pending deployment. If credentials were disclosed, revoke or rotate them with their issuer.
