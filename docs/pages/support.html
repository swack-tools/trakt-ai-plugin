Support and security

Get help.
Keep your data private

For installation and ordinary bugs, use the repository’s public issue tracker. Do not include tokens, device codes, passwords, private account data, or full conversation transcripts.

A useful bug report

  • Client name/version and whether you installed the plugin, standalone skills, or standalone MCP.
  • The failing step and sanitized error code.
  • Whether authentication completed, without sharing its codes or credentials.
  • A minimal reproduction using an ordinary title query rather than personal history.

See connection troubleshooting first. No response-time SLA or verified support inbox is currently advertised.

Security-sensitive reports

Send private reports to security@swacktech.com for private security reports to SwackTech LLC. Include a minimal reproduction, affected version, impact, and a safe way to contact you. Do not publish exploit details or account data in a public issue, and do not send live tokens or unnecessary personal data by email.

The repository security policy records current reporting boundaries. If you exposed a token, revoke it with the issuing service; deleting a public message does not invalidate the credential.

Account deletion

Client disconnection and service-side deletion are different. Read the privacy page for connection deletion and upstream revocation. Never put your connection token in an issue to request deletion.
