A connection that belongs to you

One account.
Your own history

Trakt MCP is a multi-user Rust/WASM service on Cloudflare Workers. Each authorization has its own stored credentials and connection. You don’t need the operator’s Trakt login, client secret, or hosting setup.

Read tools leave your account unchanged. With write permission, you can request specific watchlist, history, rating, collection, and list changes. Recommendations use Trakt’s ranking; this service does not train a separate ratings model.

Three steps to connect

  1. Install the plugin or add the remote MCP server.
  2. Approve your own Trakt account with a device code.
  3. Start a new conversation and ask about your viewing.

Tools with a useful procedure

The plugin bundles seven skills for recommendations, viewing profiles, title search, lists and watchlists, release calendars, library changes, and connection help. Nine MCP tools include an inspectable API catalog. Skills preserve complete-history traversal and bounded recent viewing; requested writes require permission and a readback check.
